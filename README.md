# ⚡ Daily Routine & Focus Tracker (Qarshi City Edition)

Ushbu veb-ilova mustaqil hayot, intizom, Machine Learning (nazariya, amaliyot va grant darslari), sport, tillar (Ingliz tili va Rus tili) hamda ibodat va Qur'on muraja'asini ideal muvozanatda ushlab turish uchun maxsus ishlab chiqildi.

---

## 🎯 Asosiy Imkoniyatlar

1. **2 xil rejim + Yakshanbalik reja:**
   - 🚀 **Toq kunlar (Dushanba · Chorshanba · Juma):** ML Grant kunlari (19:00–21:00 dars, 17:00–18:30 sport zali, zaldan to‘g‘ridan-to‘g‘ri darsga o‘tish va Shom namozi eslatmalari).
   - 🎯 **Juft kunlar (Seshanba · Payshanba · Shanba):** Mustaqil chuqur rivojlanish, portfolio loyihalar, o‘qish, kitob mutolaasi va oila bilan muloqot.
   - 🌿 **Yakshanba:** Kvartirani tozalash, ovqat tayyorlash, dam olish, sayr va **Haftalik tahlil (Weekly Audit)**.

2. **Real-time Live Tracker (Hozirgi mashg‘ulot):**
   - Kompyuteringiz soatiga qarab avtomatik ravishda hozirgi mashg‘ulotni aniqlaydi.
   - Necha daqiqa o‘tgani va qancha vaqt qolganini real vaqtda countdown va chiroyli progress-bar orqali ko‘rsatadi.
   - Keyingi mashg‘ulot qaysi ekanligini oldindan ko‘rsatadi.

3. **Checklist & Confetti bayrami:**
   - Bajarilgan mashg‘ulotni bir marta bosish bilan belgilash mumkin.
   - Har bir bajarilgan vazifada salyut (confetti) va xushovoz audio signal yangraydi.
   - Ma’lumotlar brauzer xotirasida (`localStorage`) saqlanadi.

4. **⏱️ Chuqur Fokus Taymeri (Pomodoro):**
   - 25, 45, 60 yoki 90 daqiqalik chuqur diqqat rejimi (ayniqsa ML va kod yozish uchun).

5. **📊 Haftalik Tahlil (Review):**
   - Har yakshanba: ML mavzulari, GitHub commitlari, Ingliz va Rus tili natijalari, Sport mashg‘ulotlari soni, Qur'on muraja'asi va Haftalik moliya xarajatlarini qayd qilib borish imkoniyati.

6. **🕌 Qarshi shahri va mustaqil hayot eslatmalari:**
   - Namoz vaqtlari (Bomdod, Peshin, Asr, Shom, Xufton) integratsiyasi.
   - Ota-onadan uzoqda yashashdagi intizom va motivatsiya bloklari.

---

## 🚀 Qanday ochish mumkin?

Istalgan brauzerda to‘g‘ridan-to‘g‘ri `index.html` faylini oching:
```bash
open index.html
```
yoki lokal server orqali:
```bash
npx serve .
```
yoki
```bash
python3 -m http.server 8000
```
so‘ng brauzeringizda `http://localhost:8000` manziliga kiring.
